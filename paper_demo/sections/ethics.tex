\section*{Ethical Considerations}

The studio executes real tools during LIVE exploration. To prevent side
effects, the adapter enforces a default-deny rule: no tool on a
state-changing (\texttt{stateful\_write}) server is invoked unless that
server is explicitly flagged sandboxed, and exploration and scoring
otherwise operate only against read-only servers, so no real external state
is modified. REPLAY mode touches no network at all. The system handles no
personal data; the public servers in the default showcase expose only public
market, scholarly, and encyclopedic data. The work conforms to the ACM Code
of Ethics.

\section*{Use of Large Language Models}

LLMs are the objects of study (the agents under evaluation), components of
the pipeline the studio wraps (the goal generator, the explorer agent, and
the optional Tier-2 effect-equivalence judge), and were additionally used to
assist with copy-editing this manuscript. All system design, experiments,
and analysis are the authors' own.
