# Benchmark Advisor context

For Benchmark Advisor work, start by reading:

- `docs_benchmark_advisor/CONCEPT.md` for the module thesis, boundaries, and workflow.
- `docs_benchmark_advisor/PLAN.md` for the current claim ledger, step ids, dependencies, and done-when criteria.

Do not preload every file under `docs_benchmark_advisor/planning/` into the default context. After identifying the current BA step or task area from `PLAN.md`, open only the relevant planning contracts, task packets, fixtures, or implementation files needed for that task.
