# E9.14 — Is the scorer's strictness model-independent?

- status: done (2026-08-02)
- ledger: camera-ready commitment **3.4**
- promised to: reviewer **1npx** — *"this covers one model, so we cannot yet show
  the strictness is model-independent … Every model faces the identical replay
  and rule, so we expect it to move the level rather than the ordering, and will
  validate that for the camera-ready."*
- result: **negative** — it is not. The scorer under-credits capable models far
  more than weak ones (66.7% against 8.3%), and on the four models measured the
  correction reorders the top pair. The claim we sent the reviewer does not hold
  and is retracted here.

## Question / hypothesis

The first human pass covered one model. Its headline finding was that the scorer
is conservative: it failed about half the runs a human would pass. We told the
reviewer we expected that conservatism to be roughly uniform, so it would lower
the level without disturbing the ranking.

- **H1.** The false-negative rate, P(human passes | scorer failed), is within a
  few points across models spanning the capability range.
- **H2.** Reconstructed human pass rates preserve the published ordering.

Pre-registered rule: **positive** if both hold; **negative** if either fails.

## Method (+ reproduce command)

Only the two strata where the scorer and humans can disagree are annotated, and
only the third question of the original instrument is asked, so the load is a
fraction of the first pass.

- Models: `gemma4-31b` (42.5 pass^3), `qwen3-8b` (22.1), `smollm3-3b` (7.2),
  against the already-annotated `qwen3.6-35b` (48.5) as baseline.
- Per model: 60 scorer-FAIL cards, 4 per task category, plus 10 scorer-PASS.
- 6 raters, 240 card-judgments over 210 unique items, 20 shared cards at three
  votes. Shared cards resolved by majority. First attempt only, seed 0.

```bash
uv run python scripts/cr34_annotation_package.py --out annotations/cr34
uv run python scripts/annotate2.py report --suffix _v2 --pull
```

## Result

**Negative on both hypotheses.**

### H1: the strictness is not uniform

| model | pass^3 | P(human passes given scorer failed) | 95% CI | n |
|---|---|---|---|---|
| `gemma4-31b` | 42.5 | **66.7%** | 54.1 – 77.3 | 60 |
| `qwen3.6-35b` (baseline) | 48.5 | 49.9% | 45.3 – 54.5 | 461 |
| `qwen3-8b` | 22.1 | 25.0% | 15.8 – 37.2 | 60 |
| `smollm3-3b` | 7.2 | **8.3%** | 3.6 – 18.1 | 60 |

An eightfold spread; the extreme intervals are nowhere near touching.

### H2: the ordering does not survive

Human pass rate is `P(auto-pass) x P(human pass | auto-pass) + P(auto-fail) x
P(human pass | auto-fail)`, the first factor taken exactly from the released
verdicts.

| model | by the scorer | by humans | shift |
|---|---|---|---|
| `gemma4-31b` | 44.9% | **81.6%** | +36.7 |
| `qwen3.6-35b` | 54.0% | 74.2% | +20.2 |
| `qwen3-8b` | 27.5% | 40.1% | +12.6 |
| `smollm3-3b` | 15.5% | 19.4% | +3.9 |

By the scorer `qwen3.6-35b` leads; by humans `gemma4-31b` does. The swap survives
the interval: even at the lower bound of gemma's false-negative rate its human
pass rate is 74.7%, against 74.2% for a baseline measured on n=461.

### Where the effect comes from

Two mechanisms, and they are separable.

**Part of it is what the model failed on.** Capable models get further, so their
failures concentrate in `value_produced` — the tool work was done but the final
message did not match the evidence predicate — while weak models never reach that
point.

| model | checkpoints met | failed on `value_produced` only | `tool_effect` unmet |
|---|---|---|---|
| `gemma4-31b` | 62% | 58% | 42% |
| `qwen3-8b` | 34% | 30% | 70% |
| `smollm3-3b` | 12% | 10% | 90% |

And the kind of failure predicts the human verdict much better than chance:
pooled, a `value_produced`-only failure is passed by a human **64%** of the time
(n=59) against **19%** when a `tool_effect` is unmet (n=121).

**But that is not most of it.** Standardising every model to the pooled mix of
failure kinds barely moves the top and lifts only the bottom:

| model | observed | standardised to a common failure mix |
|---|---|---|
| `gemma4-31b` | 68.3% | 64.7% |
| `qwen3-8b` | 25.0% | 26.0% |
| `smollm3-3b` | 8.3% | 18.9% |

A 45-point gap remains. Composition explains roughly a quarter of the effect, at
the weak end only.

**The residue looks like unlisted equivalent paths.** Inside the `tool_effect`
unmet stratum, `smollm3-3b` averages **0.5** successful tool calls on the runs a
human passed: it is not being judged harshly, it did nothing, and the human
agrees. `gemma4-31b` averages 3.0 and still misses the required checkpoint. That
is the shape of a model reaching the effect by a route the spec's equivalence set
does not list, which is precisely the limit we disclosed to this reviewer as
measured for precision but not for recall.

### Controls

- The Tier-1 scorer is deterministic code, identical for every model. No model is
  in the scoring loop, so "a stronger scorer" is not the axis.
- Distiller family is evenly spread across the three samples (openai 37/44/37%,
  z-ai 21/21/26%, anthropic 24/16/13%), so the checkpoints were not written by
  systematically different authors per model.
- Every model gets the same category allocation, so this is not a difference in
  which tasks each happened to fail.

## Result classification: **negative**

Both registered hypotheses fail. We are reporting it because the claim it
refutes is one we already put in front of a reviewer.

## Conclusion & implication

The scorer's conservatism is real, already disclosed, and **not uniform**: it
grows with how close the model got. Reported accuracies remain lower bounds, but
the bound is tighter for weaker models, so the published table understates the
spread and cannot be trusted to order two models separated by a few points.

Two concrete repairs, both now with an address rather than a hunch:

1. **Relax `value_produced` matching.** It carries the larger share of
   over-strict failures and only ever costs a model credit for work it did.
2. **Widen equivalence sets, and measure their recall.** The residual effect is
   consistent with capable models taking routes the sets do not enumerate.

Neither can lower a score; both raise the floor unevenly, which is the point.

Scope and caveats, which belong with the numbers: 60 cards per model give ±13
points; the pass stratum is 10 cards per model and bounds only a gross departure
from the baseline's 95%; and the baseline itself was collected with the older
three-question instrument over the full 750, so it is not measured identically.
The reordering is between two models 3.6 points apart in the published table,
which is inside the range this experiment says should not be read as an ordering.
