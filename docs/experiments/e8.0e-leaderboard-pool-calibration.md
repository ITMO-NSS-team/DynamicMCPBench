# E8.0e — 8-model leaderboard-pool calibration

## Question / hypothesis

Before committing the leaderboard run on the merged 1527-spec HF corpus,
measure accuracy + $/spec for the proposed 8-model pool — the E8.0d
5-model OR pool minus `gpt-oss-120b`, plus four frontier-adjacent
additions (`qwen3.7-max`, `grok-4.3`, `gpt-5.4-mini`, `haiku-4.5`).
The pool-mean token-profile estimate projected ~$0.084/spec; is it right?

## Method

Identical condition to E8.0a/E8.0b/E8.0d for comparability: `dmcp eval
--replay --pool target --p-alt 0.5 --pool-size 8 --budget 12`, N=10 on
`specs/v3.jsonl`. Sequential cells on one `OPENROUTER_API_KEY`.
Direct cost: **\$0.71**; wall time ~50 min.

## Pre-registered decision rule

Calibration only — records the planning input for the leaderboard run.

## Reproduce

```
uv run python scripts/cost_calibration.py \
  --models "deepseek/deepseek-v4-pro,z-ai/glm-5.1,moonshotai/kimi-k2.6,minimax/minimax-m3,qwen/qwen3.7-max,x-ai/grok-4.3,openai/gpt-5.4-mini,anthropic/claude-haiku-4.5" \
  --n 10 --specs specs/v3.jsonl --reference-traces traces/v3.jsonl \
  --manifest manifests/servers.json --concurrency 8 \
  --out reports/cost_calibration_or8 --json docs/experiments/e8.0e_numbers.json
```

### Leaderboard cost projections

| Scope | pass^1 | pass^3 |
|---|---|---|
| 710 valid E8.7-v2 specs | \$50 | \$151 |
| **1527 merged HF corpus** | **\$108** | \$325 |

(+5–10% Tier-2 judge overhead on top.)

### Findings

1. **Four models tie at 90%** on N=10: minimax-m3, kimi-k2.6, glm-5.1,
   qwen3.7-max — a real race at the top for the full-corpus run.
   minimax-m3 remains the cost Pareto winner ($0.0037, also fastest p50
   among the 90% club).
2. **The pool-mean token-profile estimate was ~18% high** ($0.084 vs
   $0.071 measured/spec): the four unmeasured models all came in at or
   below the projected profile — none is a token guzzler under a
   12-turn budget.
3. **`gpt-5.4-mini` is the accuracy floor (50%)** despite blazing
   latency (1.2 s p50) and near-minimal output (244 tok/spec — it
   under-engages with the tool loop). Useful as the speed/cheap anchor,
   not a contender.
4. **`grok-4.3` and `haiku-4.5` are the latency champions** of the
   competitive set (1.8–2.0 s p50) at mid-pack accuracy — they'll make
   the latency/accuracy Pareto interesting even if they don't win
   outright.
5. **deepseek-v4-pro's 19.7k input tokens/spec** (2.4× pool median)
   persists from E8.0d — its agent loop re-reads context aggressively.

## Conclusion (classification: **positive**)

The 8-model pool is healthy: every model works on paid OR, no 0%
artifacts, and the full merged-corpus leaderboard prices at **~$108
(pass^1) / ~$325 (pass^3)** — within the Phase D envelope. Estimates
from token profiles were conservative in the right direction.
