# E8.9 — SAE deep-dive: P_alt degradation curves (G3.1) + distractor-strategy ablation (G3.2)

**Status:** G3.1 complete (5 models); G3.2 complete — all six distractor
strategies collected for both models, pre-registered H1 negative; the full 6-way
Holm omnibus + gen×eval heatmap **deferred to the post-acceptance appendix**
(see *Deferred* below). Committed under deadline with the data in hand.

## Question / hypotheses

The benchmark's signature failure mode is **SAE** (spurious-alternative
engagement — an agent calling a wrong-server look-alike tool). E8.9 asks whether
SAE can be *induced by distractor pressure*:

- **G3.1 (P_alt curve).** As the fraction of the offered tool pool that is
  spurious alternatives, `P_alt`, rises from 0 → 1, does agent **accuracy
  degrade** and/or does the **SAE rate rise**?
- **G3.2 (distractor-strategy ablation).** Holding `P_alt` fixed, does *how* the
  distractors are chosen change SAE? Pre-registered primary hypothesis:
  - **H1:** `SAE(hard_neg) − SAE(random) ≥ 15 pp` — adversarially-mined hard
    negatives induce substantially more server confusion than random fillers.

Prior context: **E8.10e** already found SAE pinned near the floor (0.04–1.56 %
per run across 8 leaderboard models) while **IAE** — not SAE — carried the
accuracy signal (`r(pass³, IAE) = −0.944`). E8.9 stress-tests whether that floor
is an artifact of the MAIN pool composition, or robust to deliberate distractor
pressure.

## Method

- **Subset:** `data/leaderboard_350/specs.jsonl` — 350-spec stratified slice of
  the 750-task leaderboard set. Deterministic replay (`TraceReplayRecorder`)
  against `data/merged_hf/traces.jsonl`; `manifests/servers.json`.
- **Pool:** `pool_size = 8`, `budget = 12`. For G3.1 the pool is built by
  `build_eval_pool(mode="target", p_alt=…, seed=spec.task_id.int % 2³¹)`; for
  G3.2 by `build_strategy_pool(strategy=…)`. Replay stays deterministic; the
  only model in the loop is the candidate agent.
- **G3.1:** sweep `P_alt ∈ {0, .25, .5, .75, 1}` × **5 models** (over-delivers
  the pre-registered "3 ref models"): `glm-5.1`, `deepseek-v4-pro`,
  `qwen3.7-max`, plus the two models the leaderboard later gained,
  `gemma-4-31b-it` and `qwen3.6-35b-a3b`. Wilson 95 % CIs, n = 350/cell.
- **G3.2:** 6 distractor strategies (`random`, `hard_neg`, `cross_domain`,
  `same_name`, `sibling`, `stratified`) on `glm-5.1` + `deepseek-v4-pro`,
  SAE compared with Fisher/χ² + Holm.
- **Provider pinning:** all OpenRouter calls pass
  `extra_body.provider.require_parameters=true` (the PR #110 fix) so a route that
  silently drops tool-calls can't masquerade as a 0 %/0-SAE result.

**Reproduce** (orchestrated, outage-resilient, one output file per unit):

```bash
set -a; source .env; set +a
uv run python scripts/run_e8.9_sweeps.py        # 5 curve models × 5 P_alt + 2 ablations
# single unit, e.g.:
uv run dmcp curve data/leaderboard_350/specs.jsonl --model z-ai/glm-5.1 \
  --manifest manifests/servers.json --reference-traces data/merged_hf/traces.jsonl \
  --p-alts 0.5 --pool-size 8 --budget 12 --output reports/e8.9/curve_glm-5.1_p0.5.json
uv run dmcp ablate data/leaderboard_350/specs.jsonl --model z-ai/glm-5.1 \
  --manifest manifests/servers.json --reference-traces data/merged_hf/traces.jsonl \
  --pool-size 8 --budget 12 --output reports/e8.9/ablate_glm-5.1.json
```

## Pre-registered decision rules

- **G3.1:** the degradation hypothesis is **supported** only if some model shows
  accuracy falling or SAE rising *beyond CI overlap* across `P_alt` 0 → 1.
- **G3.2 / H1:** **supported** iff `SAE(hard_neg) − SAE(random) ≥ 15 pp`
  (per model). Reported negative otherwise.

## Results

### G3.1 — P_alt degradation curves (accuracy % [Wilson 95 % CI] / SAE %)

| P_alt | glm-5.1 | deepseek-v4-pro | qwen3.7-max | gemma-4-31b-it | qwen3.6-35b-a3b |
|---|---|---|---|---|---|
| 0.00 | 59 [53–64] / 1 | 55 [50–60] / 1 | 60 [54–65] / 1 | 47 [42–52] / 0 | 50 [45–55] / 0 |
| 0.25 | 55 [50–61] / 0 | 53 [48–58] / 0 | 58 [53–63] / 0 | 47 [41–52] / 0 | 50 [45–55] / 0 |
| 0.50 | 60 [54–65] / 1 | 57 [52–63] / 1 | 61 [55–66] / 1 | 48 [43–53] / 1 | 50 [45–55] / 1 |
| 0.75 | 58 [53–63] / 1 | 57 [52–62] / 1 | 59 [53–64] / 1 | 47 [42–53] / 0 | 50 [45–55] / 1 |
| 1.00 | 57 [51–62] / 1 | 58 [53–63] / 1 | 57 [52–62] / 0 | 47 [42–52] / 1 | 51 [46–57] / 1 |

**Finding (G3.1): flat. No model degrades.** Across the full `P_alt` 0 → 1 range,
every model's accuracy stays inside its own CIs (max swing ≤ 5 pp,
non-monotone — noise, not a trend) and the SAE rate never leaves the **0–1 %
floor**. Filling the pool entirely with spurious alternatives (`P_alt = 1`) does
not measurably hurt accuracy or raise server confusion.

Notably this holds for the **weaker** models too: `gemma-4-31b-it` (47–48 %) and
`qwen3.6-35b-a3b` (50–51 %) score well below the frontier three (57–61 %) yet
show the **same** zero-SAE flatness — so SAE-immunity is not a frontier-capability
artifact. Accuracy is governed by **task difficulty, not distractor pressure**.

### G3.2 — distractor-strategy ablation (all six strategies complete)

SAE = wrong-server look-alike calls / 350; pass = fully-passing specs / 350.

| strategy | glm-5.1 SAE | glm-5.1 pass | deepseek SAE | deepseek pass |
|---|---|---|---|---|
| random | 0/350 (0.0 %) | 207/350 (59.1 %) | 0/350 (0.0 %) | 191/350 (54.6 %) |
| hard_neg | 2/350 (0.6 %) | 197/350 (56.3 %) | 2/350 (0.6 %) | 202/350 (57.7 %) |
| cross_domain | 0/350 (0.0 %) | 202/350 (57.7 %) | 0/350 (0.0 %) | 205/350 (58.6 %) |
| same_name | 2/350 (0.6 %) | 212/350 (60.6 %) | 1/350 (0.3 %) | 200/350 (57.1 %) |
| sibling | 1/350 (0.3 %) | 209/350 (59.7 %) | 1/350 (0.3 %) | 208/350 (59.4 %) |
| stratified | 1/350 (0.3 %) | 200/350 (57.1 %) | 1/350 (0.3 %) | 199/350 (56.9 %) |

**Pre-registered H1 — complete and decisively rejected.** Both arms H1 needs
(`random`, `hard_neg`) are fully collected at n = 350 for both models:

| model | SAE(hard_neg) | SAE(random) | Δ | H1 (Δ ≥ 15 pp)? |
|---|---|---|---|---|
| glm-5.1 | 0.57 % | 0.00 % | **+0.57 pp** | **No** |
| deepseek-v4-pro | 0.57 % | 0.00 % | **+0.57 pp** | **No** |

The observed effect is **~0.6 pp, ≈ 25× below the 15 pp threshold**, and the
2/350-vs-0/350 difference is not even significant (Fisher exact p ≈ 0.50). Hard
negatives do **not** induce server confusion. All six strategies sit at the
0–0.6 % SAE floor for both models, including the two adversarial constructions
(`hard_neg`, `same_name`) and the same-server `sibling` set.

## Classification & conclusion

- **G3.1 — NEGATIVE / null** for the degradation hypothesis: SAE is *not*
  inducible by raising `P_alt`, across 5 models and 25 cells. (A robust,
  publishable null.)
- **G3.2 / H1 — NEGATIVE:** pre-registered `hard_neg − random ≥ 15 pp` rejected
  (observed +0.6 pp) for both models; supporting strategies likewise at floor.

**Conclusion.** Distractor *quantity* (`P_alt`) and distractor *strategy* both
fail to move SAE off its ~0–1 % floor. This converges with **E8.10e** (SAE
0.04–1.56 %/run; IAE, not SAE, predicts the board): for current capable agents,
**spurious-alternative engagement is a near-absent failure mode, and the live
accuracy signal is incomplete aggregation (IAE), not server confusion.** The
benchmark's discriminating axis is task difficulty / multi-step aggregation, not
look-alike-tool pressure. This is reported as a faithful negative per the
results-discipline policy (a fail is a finding).

## Threats to validity

- Single 350-spec stratified subset (one seed); replay-grounded, so agent
  behaviour is conditioned on the reference tool surface.
- SAE floor is so low that per-strategy contrasts are power-limited *because the
  effect is absent* — consistent with, not masking, the null.
- Ablation run on 2 models (the pre-registered reference pair); the 5-model G3.1
  flatness is the cross-model robustness check.
