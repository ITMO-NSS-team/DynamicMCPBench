# E9.13 — Pre-submission verification sweep

**Question.** Three claims in the submitted paper could not be checked from the
repository: (a) the Reproducibility Statement asserts that all reported numbers
are regenerated from the released evaluation records — are those records
actually in the release? (b) three Gwet AC1 figures are published, but the repo
only implements Fleiss κ — can a reader reproduce them? (c) §3.4 says 16% of
effect checkpoints admit ≥2 interchangeable tools while Appendix I says 15.5%
over 4,651 — which is right, and over which population?

**Hypothesis.** All three are bookkeeping failures rather than substantive
ones: the records are in the release, the AC1 numbers are correct but
unscripted, and the two percentages are the same measurement rounded twice.

## Method

Free: network reads and local recomputation only. No LLM calls.

```bash
uv run python scripts/ac1.py --pull --check          # (b) AC1 vs e4.6_numbers.json
uv run python scripts/eqset_stats.py --pull --check  # (c) equivalence sets vs e9.13_eqset_numbers.json
```

For (a): enumerate the HF dataset with `HfApi.list_repo_files` and check the
artifacts the Statement implicitly promises.

**Pre-registered decision rule.**
- (a) *positive* if the per-run verdicts of both leaderboards are present, in
  which case the Statement is cited by path; *negative* if absent, in which
  case the Statement must be softened before submission.
- (b) *positive* if a committed script reproduces all three published AC1
  figures within ±0.005; otherwise the published figures are wrong or
  irreproducible and must be recomputed or withdrawn.
- (c) *positive* if the two percentages resolve to one labelled figure backed
  by a recomputation from the released corpus; *negative* if they turn out to
  be genuinely different measurements that were conflated (which would mean a
  real error in one of the two sections, not a rounding slip).

## Data

**(a) Release audit.** 85 files in `hf://TokenWasteGroup/DynamicMCPBench`.
Present: 8 × `leaderboard_api/verdicts/*.jsonl` (claude-haiku-4.5,
deepseek-v4-pro, glm-5.1, gpt-5.4-mini, grok-4.3, kimi-k2.6, minimax-m3,
qwen3.7-max), 16 × `leaderboard_local/verdicts/*.jsonl`, a `matrix.json`
per leaderboard, `specs.jsonl` (1,845 specs), `traces.jsonl`, `labels.json`,
`human_eval/round1/` (6 raters, 975 cards) and `human_eval/round2/` (6, 240).
Absent: `evals/cr/` — the 268 per-run files of the E9.1 tool-exposure sweep.

**(b) Agreement.** Shared κ-set of 45 tasks rated by all 6 raters:

| axis | % pairwise agreement | Fleiss κ | Gwet AC1 | published |
|---|---|---|---|---|
| validity | 99.3% | −0.004 | **0.993** | 0.99 |
| reference correctness | 72.3% | 0.317 | **0.652** | 0.65 |
| grader agreement | 84.3% | 0.534 | **0.763** | 0.76 |

`--check` exit 0.

**(c) Equivalence sets**, recomputed from the released `specs.jsonl`: 1,845
specs, 4,651 tool-effect checkpoints (plus 3,098 `value_produced`, which carry
no equivalence set and are correctly excluded from the denominator).
Distribution 3,930 / 575 / 93 / 30 / 23 for sizes 1 / 2 / 3 / 4 / ≥5, maximum
12, mean 1.213. Multi-tool: 721 = **15.502%**. `--check` exit 0.

## Result — **positive** on all three

(a) The records are there; the Statement is now cited by path rather than
softened. (b) Reproduced to the third decimal. (c) Resolved — and the premise
in the camera-ready checklist was itself wrong in a useful way: it guessed that
16% was "the 750-slice figure", i.e. a second measurement over a different
population. It is not. `PAPER_PLAN.md` §1.8 already attributed 16% to the same
1,845 specs, and the recomputation confirms 15.502% over exactly that
population. 16% was a coarser rounding of the identical number.

## Conclusion

Changes landed: `sections/reproducibility.tex` names each released artifact and
the scripts that regenerate from it; §3.4 and Appendix I both state 15.5% with
the denominator, the appendix adding mean size and the exclusion rule;
`scripts/ac1.py` and `scripts/eqset_stats.py` are committed with `--check`
modes and 22 tests, so any future drift between a published figure and the
released data fails a command instead of surviving to review.

One honest residual: the Reproducibility Statement's scope is the leaderboard
and human-study numbers. The E9.1 tool-exposure appendix draws on `evals/cr/`,
which is not in the release; its tables are regenerated from the committed
distilled numbers under `docs/experiments/data/`. The rewritten Statement no
longer claims more than that. Uploading those 79 MB would be strictly better
and is tracked in `docs/REBUTTAL_GAPS.md` §C, but it is an action on a shared
release, not a unilateral one.

Side finding worth keeping: printing Fleiss κ next to AC1 turns the paper's
choice of AC1 from a citation into an observation — validity shows 99.3% raw
agreement at κ = −0.004, the prevalence paradox in one line. That comparison is
pinned as a regression test in `tests/test_ac1.py`.
