# Does persona seeding raise goal diversity? (e1.4a)
- status: planned
- result: —

## Background — the null result that triggered this

E1.4 added persona seeding to `goal_gen` (`dmcp/personas.py`, `--no-personas`
baseline). A quick first check did **not** show the expected gain:

| condition | lexical diversity | sample |
|---|---|---|
| persona-seeded | 0.8833 | 8 goals, servers time+fetch, haiku, seed 0 |
| free-form      | 0.9098 | same |

Difference ≈ −0.025 (within noise; if anything personas were *lower*). This
experiment investigates **why** and resolves the claim either way.

## Question / hypothesis

H0 (null): persona seeding does not increase goal diversity vs free-form.
H1: it does, on a fair measurement.

Candidate explanations for the null, each addressed by the design below:
- **H-a sample**: 8 goals / 1 seed is too noisy.
- **H-b metric**: lexical Jaccard misses *intent/semantic* variety (personas
  shape what is asked, not necessarily the words — the prompt even says "don't
  name the persona").
- **H-c surface**: time+fetch is too narrow to express varied goals.
- **H-d prompt**: one call emitting N goals, with the "don't name the persona"
  instruction, may homogenize wording.

## Method (+ reproduce command)

- **Conditions**: persona-seeded vs `--no-personas`, otherwise identical.
- **Sample**: ≥ 24 goals per condition; **≥ 3 seeds** (0,1,2); report mean ± 95% CI.
- **Surface (H-c)**: richer servers — add `wikipedia` (pypi) alongside time+fetch;
  higher `--per-server`.
- **Metrics**:
  - **PRIMARY (H-b): semantic diversity** = mean pairwise embedding cosine
    *distance* over goal texts, using an embedding model if one is configured
    (OpenAI `text-embedding-3-small`, or a local MiniLM behind an optional dep).
    If no embedding backend is available, the run records that and the primary
    falls back to the structural metric below — stated explicitly in the report.
  - **SECONDARY: lexical** = `dmcp.personas.diversity_score` (always computed),
    plus distinct-bigram ratio.
  - **Qualitative**: include a few example goals per condition.

Reproduce (per seed S, then aggregate):
```
uv run dmcp goal-gen --server time --server fetch --server wikipedia \
    --per-server 8 --cross-pairs 0 --seed S -o /tmp/g_persona_S.json
uv run dmcp goal-gen --server time --server fetch --server wikipedia \
    --per-server 8 --cross-pairs 0 --seed S --no-personas -o /tmp/g_free_S.json
# then compute primary+secondary metrics over the goal texts (script recorded here)
```

## Decision rule (pre-registered — fixed before running)

On the **PRIMARY metric**, persona-seeding is **positive** iff its
seed-averaged score exceeds free-form by **more than the 95% CI half-width**
(non-overlapping intervals). If intervals overlap → **neutral**. If free-form is
higher beyond CI → **negative**. The lexical metric is descriptive only and does
NOT override the primary.
