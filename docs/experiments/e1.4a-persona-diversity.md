# Does persona seeding raise goal diversity? (e1.4a)
- status: done
- result: neutral (primary); secondary lexical metric mildly negative

## Background — the null result that triggered this

E1.4 added persona seeding to `goal_gen` (`dmcp/personas.py`, `--no-personas`
baseline). A quick first check did **not** show the expected gain:

| condition | lexical diversity | sample |
|---|---|---|
| persona-seeded | 0.8833 | 8 goals, servers time+fetch, haiku, seed 0 |
| free-form      | 0.9098 | same |

This experiment investigates **why** with a fairer measurement and resolves the
claim either way.

## Question / hypothesis

H0 (null): persona seeding does not increase goal diversity vs free-form.
H1: it does, on a fair (semantic) measurement.

Candidate explanations for the first null: **H-a** tiny sample; **H-b** lexical
metric misses *intent* variety; **H-c** narrow tool surface; **H-d** prompt shape.

## Method (realized)

Reproducer: `docs/experiments/e1.4a_run.py` — `uv run python docs/experiments/e1.4a_run.py`.

- **Conditions**: persona-seeded vs `--no-personas`, identical otherwise.
- **Sample**: 16 goals per condition per seed; **3 seeds** (0,1,2). (Addresses H-a.)
- **Surface** (H-c): richer read-only servers — `time, fetch, wikipedia, arxiv`,
  `--per-server 4`, `--cross-pairs 0`. Model: `anthropic/claude-haiku-4.5`.
- **PRIMARY metric** (H-b): **semantic intent diversity** = (# distinct user
  intents) / (# goals), judged by an LLM (OpenRouter, temperature 0). *Method
  note:* the pre-registration named embedding cosine distance as primary; no
  embedding backend was available (OpenRouter doesn't serve embeddings, no OpenAI
  key, and a local model would add a heavy dependency), so the available semantic
  proxy — an LLM-judge distinct-intent ratio — was fixed as PRIMARY **before
  running** and the experiment was run **once** (no metric-shopping).
- **SECONDARY**: lexical `dmcp.personas.diversity_score`.

## Decision rule (pre-registered, fixed before running)

On the PRIMARY metric, persona-seeding is **positive** iff its seed-mean exceeds
free-form with non-overlapping ±stdev bands; **negative** if free-form is higher
beyond the bands; else **neutral**. (With 3 seeds the ±stdev band is a rough CI
proxy — treated as such.) The lexical metric is descriptive and does not override.

| metric | persona | free-form | verdict |
|---|---|---|---|
| **intent (PRIMARY)** | 0.3333 ± 0.0295 | 0.3125 ± 0.0000 | **NEUTRAL** (bands overlap) |
| lexical (secondary)  | 0.8748 ± 0.0054 | 0.9001 ± 0.0058 | negative (free > persona) |

## Result

**NEUTRAL** on the pre-registered primary metric. Persona seeding produced a
tiny, non-significant intent-diversity lean (0.333 vs 0.313, within the ±stdev
band) and was marginally *lower* on lexical diversity. **The E1.4 diversity claim
is not supported** — none of H-a (more seeds), H-c (richer servers), or H-b
(semantic metric) rescued it.

Side finding worth flagging: intent diversity is **low in both conditions**
(~0.31–0.33 → only ~5 distinct intents per 16 goals). goal-gen produces
substantial *intent redundancy* regardless of personas — a stronger lever for a
future "goal dedup / diversity-promoting selection" step than personas are.

## Conclusion & implication

- **Keep** the persona mechanism (E1.4) — it is harmless and may aid intent/role
  *realism* — but **drop the diversity justification**. Do not claim personas
  raise diversity.
- If diversity is genuinely wanted, more promising levers (future work, needs
  human sign-off before becoming plan steps): one goal per *separate* persona
  call (vs N-in-one-prompt), explicit diversity/dedup selection over generated
  goals, or stronger inter-persona contrast.
- Committed as an honest **neutral/negative** result per the Results rule. E1.4a
  is `done`.
