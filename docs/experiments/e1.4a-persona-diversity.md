# Does persona seeding raise goal diversity? (e1.4a)
- status: done
- result: neutral — confirmed by the embedding recheck (E2.2); lexical mildly negative

## Background — the null result that triggered this

E1.4 added persona seeding to `goal_gen` (`dmcp/personas.py`, `--no-personas`
baseline). A quick first check did **not** show the expected gain:

| condition | lexical diversity | sample |
|---|---|---|
| persona-seeded | 0.8833 | 8 goals, servers time+fetch, haiku, seed 0 |
| free-form      | 0.9098 | same |

This experiment investigates **why** with a fairer measurement and resolves the
claim either way.

## Question / hypothesis

H0 (null): persona seeding does not increase goal diversity vs free-form.
H1: it does, on a fair (semantic) measurement.

Candidate explanations for the first null: **H-a** tiny sample; **H-b** lexical
metric misses *intent* variety; **H-c** narrow tool surface; **H-d** prompt shape.

## Method (realized)

Reproducer: `docs/experiments/e1.4a_run.py` — `uv run python docs/experiments/e1.4a_run.py`.

- **Conditions**: persona-seeded vs `--no-personas`, identical otherwise.
- **Sample**: 16 goals per condition per seed; **3 seeds** (0,1,2). (Addresses H-a.)
- **Surface** (H-c): richer read-only servers — `time, fetch, wikipedia, arxiv`,
  `--per-server 4`, `--cross-pairs 0`. Model: `anthropic/claude-haiku-4.5`.
- **Metrics** (H-b): the first pass used an LLM-judge distinct-intent ratio as the
  semantic primary (no embedding backend was wired yet). After E2.2 added real
  embeddings, the **originally pre-registered primary** — mean pairwise cosine
  *distance* of goal embeddings (`openai/text-embedding-3-small`) — was added; see
  the Embedding recheck below. Lexical `diversity_score` is the descriptive floor.

## Decision rule (pre-registered, fixed before running)

On the PRIMARY metric, persona-seeding is **positive** iff its seed-mean exceeds
free-form with non-overlapping ±stdev bands; **negative** if free-form is higher
beyond the bands; else **neutral**. (With 3 seeds the ±stdev band is a rough CI
proxy.) The lexical metric is descriptive and does not override.

## Embedding recheck (added after E2.2 — the originally pre-registered primary)

With real embeddings available (E2.2), re-ran the same design and computed mean
pairwise cosine **distance** over goal embeddings as the PRIMARY metric:

| metric | persona | free-form | verdict |
|---|---|---|---|
| **embedding cos-distance (PRIMARY)** | 0.7736 ± 0.0168 | 0.7750 ± 0.0055 | **NEUTRAL** (overlap) |
| intent (LLM-judge) | 0.3125 ± 0.0510 | 0.2917 ± 0.0295 | NEUTRAL (overlap) |
| lexical            | 0.8766 ± 0.0098 | 0.9052 ± 0.0058 | negative (free > persona) |

The embedding primary is essentially identical between conditions (0.774 vs
0.775) — **NEUTRAL confirmed**. Across all three metrics (embedding, intent,
lexical) persona seeding does not raise diversity, so the conclusion is robust to
the metric and not a lexical-scoring artifact.

## Result

**NEUTRAL** on the pre-registered primary (both the embedding and the interim
intent metric); lexical mildly negative. **The E1.4 diversity claim is not
supported** — H-a (more seeds), H-c (richer servers), and H-b (semantic /
embedding metrics) all fail to rescue it.

Side finding: intent diversity is low in both conditions (~0.31 → ~5 distinct
intents per 16 goals) — goal-gen produces substantial intent *redundancy*
regardless of personas, a stronger lever for a future "goal dedup /
diversity-promoting selection" step than personas are.

## Conclusion & implication

- **Keep** the persona mechanism (E1.4) for intent/role *realism*, but **drop the
  diversity justification** — do not claim personas raise diversity.
- If diversity is wanted (future work, needs human sign-off before becoming plan
  steps): one goal per *separate* persona call (vs N-in-one-prompt), an explicit
  diversity/dedup selection over generated goals, or stronger inter-persona contrast.
- Committed as an honest **neutral/negative** result per the Results rule,
  confirmed across lexical, LLM-intent, and embedding metrics. E1.4a is `done`.
