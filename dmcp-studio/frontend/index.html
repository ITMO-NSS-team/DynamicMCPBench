Stage 1 — Substrate

Pick the live MCP servers to benchmark

Point the studio at servers you already run, or use the public set. The pipeline collects each server's tool surface and tags it by dynamism. Nothing here is a fixed dataset — these tools are live.

Bring your own MCP server · registers & explores in LIVE mode
Read-only servers only. A stdio command is split on spaces (no quoting); an http(s):// value registers a streamable-HTTP server. State-changing servers are refused unless sandboxed.

Stage 3 — Distillation

Compile the trace into a path-agnostic TaskSpec

The distiller turns the successful trace into effect checkpoints, optional minefields, and a partial order. A checkpoint demands an effect — that some tool from an equivalence set ran with the right arguments, or that a value appeared — never a specific path. Every required tool was actually used, so a spurious "unnecessary tool" can't appear.
