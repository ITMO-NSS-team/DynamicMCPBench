DISTILLER FIDELITY

We are dropping the claim that spurious requirements are impossible by construction. Trace grounding buys provenance and achievability; necessity depends on the distiller and validator, so it must be measured.

We audited 100 TaskSpecs by hand from the released corpus: 264 retained tool_effect checkpoints, 200 of the non-retained reference calls, 67 listed alternatives.

| audited | result | Wilson 95% CI |
|---|---|---|
| checkpoints grounded in a successful call | 261 / 264 = 98.9% | 96.7 - 99.6 |
| of those, judged necessary to the goal | 261 / 261 = 100% | 98.5 - 100 |
| non-retained calls redundant or irrelevant | 188 / 188 resolved = 100% | 98.0 - 100 |
| TaskSpecs missing a required effect | 1 / 100 = 1% | 0.2 - 5.4 |
| listed alternatives judged effect-equivalent | 67 / 67 = 100% | 94.6 - 100 |
| specs valid as written (4 minor, 1 permissive) | 95 / 100 | |

Twelve further non-retained calls were unresolved, mostly recovery after a failure; counting all twelve as errors gives 94%.

The missing effect was never executed in the reference trace, so it is a reference-validation miss, not a distillation one; we will fix the task and tighten the validator.

Two caveats. The equivalence figure is precision over listed alternatives, not recall over every equivalent tool. And distiller output is not accepted blind: each spec passes a fourth-family validator and a deterministic trace check.

ALTERNATIVE CALLS, ARGUMENTS, DECOMPOSITIONS

Replay fixes the recorded world, not the action sequence, so your three cases differ.

A different decomposition passes if it produces every required effect, trips no minefield and respects the partial order. Independent steps may run in any order, and extra calls are ignored by the scorer.

Differently represented arguments are handled: replay serves the cached result when the candidate's arguments match a recorded call closely enough under a deterministic field-level comparison with a string-similarity fallback, no model involved. Not a corner case: it served 8 to 11 percent of all cached calls for the strongest API and local models.

A call the reference never made is where replay binds: it has no cached result, so it returns an error to the agent, and a checkpoint requiring a successful call will not credit it. Scoring accepts any member of an equivalence set, but replay serves only what was recorded. We screen the released corpus so a spec its own reference cannot satisfy is dropped rather than counted as a model failure, but a candidate cannot find a route the reference never took. We measured how often that binds: for those two models it blocked a listed alternative on 7 to 9 percent of tasks. Unrestricted path freedom exists only in live mode, which the framework supports and the leaderboard does not use, because determinism is what makes 24 models comparable.

TIER-1 VERSUS TIER-2

Every number in the paper comes from deterministic scoring: the judge was never enabled, so the difference is zero throughout and no reported claim rests on model judgment. Where we did enable it, on a 200-cell subset at one attempt, it was invoked 120 times, upgraded 7 checkpoints and flipped 3 cells, moving 96 of 200 to 99, about 1.5 points. Those records carry no category label; per-category rates come in the camera-ready.

Agreement is 73.7% and 94.9% of automatic passes are confirmed.

Two things about the shape. The error is one-directional: the scorer almost never credits work that is not there, so the leaderboard cannot be inflated. And the two parties answered different questions. Annotators read a run and said whether it looks done; the scorer asks whether the required effects are demonstrably present. The gap is the strictness we chose, not a defect rate, and it is the lower-bound property we state in Limitations, now quantified.

The limit we should own: this covers one model, so we cannot yet show the strictness is model-independent. Every model faces the identical replay and rule, so we expect it to move the level rather than the ordering, and will validate that for the camera-ready.
